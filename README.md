# Agência JVI

Landing page da Agência JVI.

> Do boca a boca ao digital.

## Stack

- Vite + React + TypeScript
- Framer Motion, GSAP/ScrollTrigger, Lenis (smooth scroll)
- Fontes auto-hospedadas (Anton, Oswald, Inter)

## Rodando localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```
